Changelog

Todas as mudanças relevantes do Cofree serão documentadas neste arquivo.

O formato segue uma organização por versões, com datas e categorias de alterações para facilitar o acompanhamento do desenvolvimento.

[0.1.0] - 2026-10-24

Adicionado

- Estrutura inicial do projeto Cofree.
- Interface gráfica utilizando CustomTkinter.
- Janela principal com barra lateral, cabeçalho e área de conteúdo.
- Navegação entre as páginas Painel, Movimentações, Categorias e Metas.
- Tela inicial para cadastro do saldo inicial.
- Validação do saldo inicial informado pelo usuário.
- Armazenamento local de dados utilizando JSON.
- Módulos separados para operações financeiras e validações.
- Componentes visuais para cartões, categorias, metas e indicadores financeiros.
- Centralização das cores da interface.
- Módulo dedicado à definição da versão do aplicativo.
- Exibição da versão atual no rodapé da barra lateral.

Em desenvolvimento

- Implementação completa das operações financeiras.
- Integração das páginas com a lógica de movimentações, categorias e metas.
- Aprimoramento dos relatórios e indicadores financeiros.
- Testes e melhorias na confiabilidade do aplicativo.

Observações

- Esta versão representa uma etapa inicial do desenvolvimento.
- Algumas ações da interface ainda são protótipos visuais e não executam operações financeiras completas.
